# Python-Programming-Lab-Assignments

## Course Description
This repository contains Python programs developed as part of the Python Programming Lab for Semester III (Computer Science Engineering), strictly based on the prescribed syllabus.

## Objectives
- Understand basic Python programming concepts  
- Develop programs using Python data types and data structures  
- Implement functions, classes, and modules  
- Perform file handling and exception handling  

## List of Experiments

1. Python Basics and Input–Output  
2. Operators in Python  
3. String Operations  
4. Control Structures (Loops)  
5. List Operations  
6. Dictionary Operations  
7. Functions and Modules  
8. Mini Project using Functions  
9. Classes and Object-Oriented Programming  
10. ATM Application using OOP Concepts  
11. File Handling  
12. Exception Handling  

## Tools & Technology
- Language: Python 3.x  
- IDE: IDLE / VS Code  

## Course Outcomes
- Apply Python programming principles  
- Develop basic Python applications  
- Use lists, tuples, sets, and dictionaries  
- Handle runtime and application errors
